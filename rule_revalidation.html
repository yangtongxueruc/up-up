① 现行规则：6 条已死，2 条样本外失效
A / B / C / D / X / R 六条规则在 83 天全样本上组合 α 全部为负（−0.10% ~ −0.23%/日）， 扣 0.20% 往返成本后净 α −0.30% ~ −0.43%，Romano–Wolf 多重检验 p 值 ≥ 0.62，无一显著。 S（动量 S）与 MF（多因子 Top30）全样本显著（pRW=0.011 / 0.030）， 但样本外（2026-07-15 起）分别衰减到 −0.19% / −0.10% 净 α，同样不可用。
② 新发现：尾盘 tail 是唯一稳健信号
定义 tail = 收盘 / 14:30价 − 1。样本内 IC −0.0755（t=−5.32，pRW=0.0003）， 用 5 分钟 K 线独立重算得到 IC −0.0785（t=−6.50），与原口径 Pearson 相关 0.9845。 规则「尾盘 ≤ 0」样本外 α +0.208%（t=+3.54，胜出 24/34 天，4/4 个月为正）。
③ 板块当日涨幅：单独无效，但作为交互条件有效
板块层面特征直接 IC 全部不显著：bd_chg_close IC=+0.0029（t=0.17，pRW=0.91）、 bd_breadth IC=+0.0143（t=0.83）。直接把板块特征塞进线性复合打分反而变差 （样本外 α 从 −0.047% 降到 −0.074%）。

④ 最佳可用组合：B5「超板块 ≥0 且 板块当日强」
样本内净 α +0.292%（pRW=0.001）→ 样本外 α +0.334%、 扣 0.20% 成本后净 α +0.134%、滚动 4 段全部为正（+0.39/+0.68/+0.53/+0.11）、 日均命中 142.7 只。成本提高到 0.30% 时仍为 +0.034%。
⑤ 两个必须知道的负面结论
（a）浓缩无效：在 B4 集合内按 −tail 排序取前 30 只，样本外 α 变成 −0.257% （4 个月全部为负）。该信号靠广度而非强度挣钱，打分排序会摧毁它。
（b）14:30 决策口径下没有信号：口径 A（只能用 14:30 及之前信息）搜索出的 5 个候选， 样本外全部为负，净 α −0.10% ~ −0.24%。信号只存在于 14:30→收盘这段，只能收盘下单。

二、新规则探索

2.1 数据面板与防过拟合设计

  • 面板：59,596 条「股票×日」观测，83 个交易日（2026-05-06 ~ 2026-08-31）。每个观测含 24 个基础特征 （涨幅 / 换手 / 量比 / 振幅 / 活跃度 / 5–60 日动量 / 量能比 / 距离 60 日高低点 / 流通市值等） + 6 个仅收盘可得特征（全日涨幅、尾盘 tail、相对板块 rel_chg_close 等） + 8 个板块特征。
  • 板块定义：从 themes.json 取行业字段，保留 panel 内成员 ≥5 的行业，共 109 个。 板块指标（当日涨幅、上涨广度、板块尾盘）全部等权、且严格只用当日及之前的信息，无前视。
  • 观测单位 = 天。同日个股收益高度相关（市场 β 约占 60–70% 方差）， 若把 59,596 行当独立样本，有效样本量会被高估约 700 倍。因此所有推断都在「日 α 序列」上做（D=83）。
  • 多重检验：Romano–Wolf stepdown max-|t|（3,000 次重抽），并用 Benjamini–Hochberg FDR 与 Bonferroni 交叉验证。
  • 样本切分：样本内 2026-05-06 ~ 2026-07-14（49 天）做全部参数估计与筛选；样本外 2026-07-15 ~ 2026-08-31（34 天）只做一次确认。
  • 分阶段搜索：Stage A 定方向（24 特征）→ Stage B 定阈值（每特征 3 个分位）→ Stage C 两两 AND（仅前 6 名）， 每阶段内部各自做 RW 校正，把搜索空间压到最小。
  • 成本：往返 0.20%（佣金 0.025%×2 + 印花税 0.05% + 冲击/滑点约 0.10%），并在 0.10%~0.30% 做敏感性。

四、结论与落地建议

对用户三个问题的直接回答

① 现行规则还有效吗？ 否。A/B/C/D/X/R 六条组合 α 全为负（−0.10% ~ −0.23%/日）， 多重检验 p ≥ 0.62；S 与 MF 全样本显著但样本外（7/15 起）净 α 分别为 −0.19% / −0.10%。 建议撤下站点上 S / MF 的「显著」标签，改标「全样本显著 · 样本外失效」。
② 有新规则吗？ 有，但只能用「收盘下单」口径。 尾盘 tail ≤ 0（收盘不高于 14:30）是唯一通过全部检验的新信号： 独立数据源可复现（Pearson 0.98）、4/4 个月 + 6/6 种大盘状态全正、样本外 t=+3.54。 但扣 0.20% 成本后净 α 仅 +0.008%，必须叠加板块条件才够厚。
③ 板块当日涨幅能加吗？ 能加，但只能作为「条件」而非「打分」。 板块涨幅/广度单独 IC ≈ 0.003~0.014（t<0.9，pRW>0.86），加进线性复合反而使样本外恶化 27bp。 正确用法是交互：B5「个股全日相对板块 ≥0 且 板块当日涨 ≥0.5% 且 尾盘 ≤0」， 样本外净 α +0.134%，成本容忍到 0.30%。

落地建议（按优先级）

  • P0 — 先止损。把站点上 A / B / C / D / X / R 的灰度标记改为明确「已证伪」； S 与 MF 的看板话术从「显著」改为「全样本显著、样本外已衰减至 0，不再作为推荐信号」。 这两条现在每天还在给使用者错误的方向性暗示。
  • P1 — 尾盘信号另起炉灶，不要塞进 14:30 日页面。它必须收盘定价、次日 11:30 卖出， 与现有「14:30 筛选 + 次日早盘回填」的产品形态不兼容。建议做成一个独立的 「收盘榜单」模块（每日 15:05 生成，列出当日满足 B5 的全部个股，日均约 143 只）。
  • P2 — 等权全买，不要精选。浓缩到 30 只会把样本外 α 从 +0.28%% 打成 −0.26%%。 日均 143~232 只意味着这实质是一个指数增强式的组合，不是选股榜单—— 产品形态上应当按「组合」而不是「牛股列表」来呈现。
  • P3 — 持续监控信号衰减。滚动前向最后一段（第 5 段）已降到 +0.017%%， 8 月月度 α 也从 7 月的 +0.339%% 降到 +0.107%%。建议设定失效阈值： 若连续 2 个月月度组合 α < 0，则暂停该信号。
  • P4 — 修一个数据缺陷。18.76%% 的观测 tail 恰好为 0， 这是 backfill 取不到收盘价时 fallback 到 14:30 价造成的。 修复后信号强度还会更高（当前是被稀释的状态）。

附录：方法论与防过拟合清单

  • 为什么以「天」为观测单位。同一交易日的个股收益相关性极高（市场 β 解释 60–70% 方差）。 59,596 行观测若按独立样本计算 t 值，会把有效样本量高估约 700 倍。本文所有 t / p / 置信区间 都在日度组合 α 序列上计算（D=83）。
  • 横截面中心化。αd = mean(命中股次日收益) − mean(当日全部候选股次日收益)。 衡量的是相对「直接买入整个筛选池」的增量，自动剔除大盘涨跌的影响。
  • 条件 α vs 组合 α。条件 α 只统计触发日（衡量信号强度）； 组合 α 把每一天都算进去，未触发日记 0 超额（衡量真实可交易性）。本文以组合 α 为准。
  • Wild bootstrap（Rademacher）。对每日去均值后的 α 乘 ±1 重抽，4,000 次， 保留横截面相关结构、对异方差与波动聚集稳健；用于置信区间与符号检验。
  • Romano–Wolf stepdown。3,000 次重抽下 bootstrap max|t*| 的零分布， 逐步剔除显著者并单调化 p 值。使用双侧（显著为负同样是发现，例如「换手越高越差」等价于「低换手更好」）。 并用 BH-FDR 与 Bonferroni 交叉验证。
  • 日期对齐的 α 矩阵。不同规则的有效日集合不同；RW 必须在按日期对齐的矩阵上做， 按位置截断会把不同日期拼接到一起，产出无意义的结果（本项目前期踩过此坑）。
  • 纯净的 IS / OOS 切分。2026-05-06 ~ 2026-07-14（49 天）做全部估计与筛选；2026-07-15 ~ 2026-08-31（34 天）只用于最终确认， 不在 OOS 上做任何参数调整或规则挑选。
  • 预注册的交互族。B0–B7 在看到 OOS 之前就全部定义好，IS 内只选 1 条，OOS 只验这 1 条—— 避免「看完答案再选题」。
  • 分阶段搜索 + 每阶段 RW 校正。A 阶段 24 个方向 → B 阶段每方向 3 个分位 → C 阶段只对前 6 名做两两 AND， 把实际试验次数从数千压到 22（口径 B）/ 19（口径 A）。
  • 独立数据源复核。关键信号 tail 用完全独立的数据源（5 分钟 K 线的 15:00/14:30 bar） 重算 318,541 条做交叉验证，Pearson 0.9845。
  • 伪影排查。检查并剔除回填兜底造成的退化观测（18.76%）后重算，确认效应不是数据缺陷的产物。
  • 成本与容量。往返 0.20% 基线，0.10%~0.30% 敏感性；报告日均命中只数以反映容量约束。
  • 环境。纯 Python 标准库实现（无 numpy/scipy），全部统计量（正态尾概率、秩相关、分位、bootstrap）手写。 随机种子固定 20260901，结果可复现。
本研究的局限（务必阅读）
  • 样本期只有 83 个交易日（2026-05-06 ~ 2026-08-31），且集中在单一市场环境。 即使通过了 Romano–Wolf 与滚动前向，仍不能排除未观测到的共同因子。
  • 样本外仅 34 天，B5 的样本外 t=+1.86 未达显著。它「通过了流程」不等于「已被证明」。
  • 信号已在衰减：滚动前向最后一段 +0.017%，8 月月度 α 较 7 月下降约 68%。
  • 未考虑的实际摩擦：涨跌停无法成交、流动性约束、日均 143~232 只的调仓冲击、 个股停牌剔除等，都会使实盘结果低于本文数字。
  • tail 变量依赖 14:30 快照与收盘价两个数据源的一致性； 18.76% 的观测存在回填兜底导致的退化值，虽经排查不影响结论，但会稀释信号强度。
