五、结论

⚠️ 关键修正（相比旧版 3 天 / 7 天结论）：扩样至 63 锚点后，规则 A 的整体超额收敛至零附近（0.3pp），不再显著优于基准——早期「超额」主要来自 08-03~08-11 几个特定弱势日的 regime 运气。其超额高度依赖当日大盘 regime（见下表）：仅「平 / 跌」档正向，「涨 / 弱跌」档反而跑输基准。本质是「均值回归 / 避雷」过滤器而非无脑买入信号：弱势日躲开进一步下挫，普涨日放弃已冲高的票、牺牲部分收益。因此它是条件性策略。

次日较可能收涨的组合（按强度，全量样本）：
  • 首选：当日14:30涨幅 ≤0.6% 且 换手率 ≥2% → 40.4% 收涨、均 +-0.34%（n=3929，相对基准 0.3pp）。
  • 更精选：涨幅 ≤0.6% 且 换手率 ≥3% 且 量比 ≤1.2（规则C）→ 41.0% 收涨、均 +-0.38%（n=1584）。
  • 共性：活跃度等级 4-5 次日收涨率优于 1-2 级；涨幅越小越好（强单调）。
关于「过度冲高」（反例E，涨幅>1.5%）：合并样本次日收涨率 42.8%（n=37364），略高于基准——说明它并非简单反向指标。它只在弱势/震荡日拖后腿，在普涨日反而随大盘走强。故「避雷」价值是条件性的，不能机械回避所有冲高票。
重要风险提示
1. 本页仍为样本内验证；历史重建日（44 个）由 sina K线重建，浮动盘/换手为近似值，存在重建误差。
2. 规则A 全量口径下超额≈0、横截面 alpha 不显著，不宜作为主信号；如需使用「跌后反弹」玩法，仅限「平 / 跌」regime 档。
3. 唯一在样本外持续显著的正向信号是IC 加权多因子复合（chg/rs 动量 + tail 反向），详见 alpha_explore / 日页「多因子 Top30」。
4. 结局为 T+1 11:30 收盘代理「收涨」，全天收盘更严格；绝对胜率由当日大盘方向主导。
5. 本页面为研究验证，不构成投资建议。
